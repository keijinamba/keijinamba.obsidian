## 概要

**電磁波**（でんじは、英: electromagnetic wave）とは、電場と磁場の変化が空間を伝播する波動現象。電磁放射（electromagnetic radiation）とも呼ばれる。真空中を光速（約30万km/s）で伝わり、媒質を必要としない。1864年に**ジェームズ・クラーク・マクスウェル**が理論的に予言し、1888年に**ハインリヒ・ヘルツ**が実験的に実証した。電磁波は波長によって電波・マイクロ波・赤外線・可視光・紫外線・X線・ガンマ線に分類され、現代文明の通信・医療・観測技術の基盤となっている。

| 項目 | 内容 |
|------|------|
| 理論的予言 | マクスウェル（1864年） |
| 実験的実証 | ヘルツ（1888年） |
| 伝播速度 | 約 299,792,458 m/s（真空中） |
| 媒質 | 不要（真空中でも伝播） |
| 性質 | 波動性と粒子性（波動粒子二重性） |
| 量子 | 光子（photon） |

## 発見の歴史

### マクスウェルの理論的予言（1864年）

1864年、イギリスの理論物理学者**ジェームズ・クラーク・マクスウェル**は、電気と磁気の法則を統一した4つの方程式（マクスウェル方程式）を導出。その解から、電場と磁場が互いに誘導しあいながら空間を波として伝播することを予言した。

**重要な洞察**:
- コンデンサ内部の電束密度の時間変化が電流と同じ働きをする（**変位電流**）
- この方程式を解くと、電場・磁場ともに波動として伝播するという結果が得られる
- 計算された波の速度が光速と一致することから、**光は電磁波である**と予想

### ヘルツの実験的実証（1888年）

1888年、ドイツの物理学者**ハインリヒ・ヘルツ**は、電磁波の存在を実験的に実証した。

| 実験内容 | 詳細 |
|----------|------|
| 送信装置 | 火花放電による電磁波の発生 |
| 受信装置 | ループアンテナによる電磁波の検出 |
| 反射板 | 亜鉛板を12m離れた位置に設置 |
| 観測した波長 | 約4m |
| 結果 | 電磁波の速度は光速と一致 |

この実験により、マクスウェルとファラデーが予言した通り電磁波が空間を伝播することが証明され、無線通信の発明への基礎が築かれた。

### その後の発展

| 年 | 出来事 |
|----|--------|
| 1895 | レントゲンがX線を発見 |
| 1897 | マルコーニがイギリス-フランス間の無線電信に成功 |
| 1900 | プランクが黒体放射の量子論を提唱 |
| 1901 | マルコーニが大西洋横断無線通信に成功 |
| 1905 | アインシュタインが光量子仮説を提唱 |

## マクスウェル方程式

マクスウェル方程式は電磁場を記述する4つの基礎方程式であり、古典電磁気学の完成形である。

### 4つの方程式

| 方程式 | 数式（微分形） | 意味 |
|--------|----------------|------|
| ガウスの法則 | $\nabla \cdot \mathbf{E} = \frac{\rho}{\varepsilon_0}$ | 電荷は電場の源 |
| 磁場に関するガウスの法則 | $\nabla \cdot \mathbf{B} = 0$ | 磁気単極子は存在しない |
| ファラデーの電磁誘導の法則 | $\nabla \times \mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}$ | 変化する磁場は電場を誘導 |
| アンペール・マクスウェルの法則 | $\nabla \times \mathbf{B} = \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \frac{\partial \mathbf{E}}{\partial t}$ | 電流と変化する電場は磁場を誘導 |

### 電磁波の導出

真空中で電荷・電流がない場合、マクスウェル方程式から波動方程式が導かれる：

$$\nabla^2 \mathbf{E} = \mu_0 \varepsilon_0 \frac{\partial^2 \mathbf{E}}{\partial t^2}$$

この解は速度 $c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}}$ で伝播する波であり、真空の誘電率 $\varepsilon_0$ と透磁率 $\mu_0$ を代入すると：

$$c \approx 299,792,458 \text{ m/s}$$

これは光速と完全に一致し、**光が電磁波であることの理論的根拠**となった。

## 電磁波の基本的性質

### 横波としての性質

電磁波は**横波**であり、電場と磁場の振動方向が進行方向に対して垂直である。

- 電場（E）と磁場（B）は互いに直交
- 両者とも進行方向に直交
- E × B の方向が進行方向（ポインティングベクトル）

### 波長・周波数・エネルギーの関係

| 関係式 | 内容 |
|--------|------|
| $c = \lambda \nu$ | 光速 = 波長 × 周波数 |
| $E = h\nu$ | 光子エネルギー = プランク定数 × 周波数 |
| $E = \frac{hc}{\lambda}$ | 光子エネルギー = プランク定数 × 光速 / 波長 |

- $c$：光速（約 3×10⁸ m/s）
- $\lambda$：波長
- $\nu$：周波数
- $h$：プランク定数（6.626×10⁻³⁴ J·s）
- $E$：光子のエネルギー

**重要な関係**：
- 波長と周波数は反比例
- 周波数が高いほどエネルギーが高い
- ガンマ線は原子サイズより短い波長を持ち、電波は数km以上の波長を持つ

## 電磁波スペクトル

電磁波は波長（または周波数）によって分類される。各領域の境界は明確に定義されておらず、連続的に遷移する。

### スペクトルの分類

| 種類 | 波長 | 周波数 | 光子エネルギー | 主な発生源 |
|------|------|--------|----------------|------------|
| 電波 | 1mm 〜 数km | 3Hz 〜 300GHz | 〜μeV | 電子回路、天体 |
| マイクロ波 | 1mm 〜 1m | 300MHz 〜 300GHz | μeV 〜 meV | マグネトロン、宇宙背景放射 |

## 波動粒子二重性

### 量子論の発展

電磁波は古典的には波動として記述されるが、微視的には粒子（**光子**）としての性質も示す。これを**波動粒子二重性**という。

| 年 | 発見者 | 貢献 |
|----|--------|------|
| 1900 | マックス・プランク | 黒体放射の量子論（エネルギーの量子化） |
| 1905 | アルベルト・アインシュタイン | 光量子仮説（光電効果の説明） |
| 1923 | アーサー・コンプトン | コンプトン効果（光子の粒子性の実証） |
| 1924 | ルイ・ド・ブロイ | 物質波仮説（粒子も波動性を持つ） |

### 光電効果

アインシュタインは光電効果を説明するため、光が**光子**という量子として振る舞うことを提唱した：

- 光子1個のエネルギー：$E = h\nu$
- 金属から電子を放出するには、光子のエネルギーが仕事関数を超える必要がある
- 光の強度（光子の数）ではなく、周波数（光子のエネルギー）が重要

→ 詳細: [[Physics/ModernPhysics/ハイゼンベルグの不確定性原理]]

### 光子の性質

| 性質 | 値 |
|------|------|
| 静止質量 | 0 |
| 電荷 | 0 |
| スピン | 1（ボース粒子） |
| 運動量 | $p = h/\lambda = h\nu/c$ |

## 電磁波の発生と伝播

### 発生メカニズム

電磁波は**加速運動する電荷**から発生する。

| 発生機構 | 例 |
|----------|------|
| 振動する電荷 | アンテナからの電波放射 |
| 原子の電子遷移 | 可視光、紫外線、X線 |
| 制動放射 | X線管 |
| シンクロトロン放射 | 高エネルギー電子の円運動 |
| 核遷移 | ガンマ線 |
| 熱放射（黒体放射） | 太陽光、赤外線 |

### 伝播の特性

- **真空中**：光速 c で伝播、媒質不要
- **物質中**：屈折率 n の媒質では速度 c/n で伝播
- **反射・屈折**：媒質の境界で起こる
- **回折**：障害物や開口部を回り込む
- **干渉**：複数の波が重なり合う
- **偏光**：電場の振動方向が特定の向きに揃う

## 天体物理学における電磁波

### マルチメッセンジャー天文学

現代の天文学では、異なる波長帯の電磁波を組み合わせた観測が行われる。2017年には重力波と電磁波の同時観測が実現し、マルチメッセンジャー天文学が始動した。

| 波長帯 | 観測対象 |
|--------|----------|
| 電波 | パルサー、クエーサー、宇宙マイクロ波背景放射 |
| 赤外線 | 原始星、塵に覆われた銀河[[マグネター]]ール降着円盤、中性子星 |
| ガンマ線 | ガンマ線バースト、マグネター |

→ 詳細: [[マグネター]]

### 赤方偏移と宇宙膨張

遠方の銀河からの光は宇宙の膨張により波長が引き伸ばされ（赤方偏移）、これが宇宙膨張の証拠となっている。
