## 概要

**光電効果**（こうでんこうか、英: photoelectric effect）とは、物質に光を照射した際に電子が放出される現象。1887年に**ハインリヒ・ヘルツ**が発見し、1905年に**アルベルト・アインシュタイン**が**光量子仮説**によって理論的に説明した。この業績によりアインシュタインは1921年のノーベル物理学賞を受賞。光電効果は、光が粒子（光子）としての性質を持つことを示す決定的な証拠であり、量子力学の誕生に大きく貢献した現象である。

| 項目 | 内容 |
|------|------|
| 発見 | ハインリヒ・ヘルツ（1887年） |
| 理論的説明 | アルベルト・アインシュタイン（1905年） |
| 実験的検証 | ロバート・ミリカン（1916年） |
| ノーベル賞 | アインシュタイン（1921年）、ミリカン（1923年） |
| 種類 | 外部光電効果、内部光電効果 |
| 主な応用 | 太陽電池、光電子増倍管、デジタルカメラ |

## 発見の歴史

### ヘルツによる発見（1887年）

1887年、ドイツの物理学者**ハインリヒ・ヘルツ**は、電磁波の実験中に陰極に紫外線を照射すると放電が起こりやすくなることを発見した。これが光電効果の最初の観測である。

### ハルヴァックスの実験（1888年）

翌1888年、**ヴィルヘルム・ハルヴァックス**は、金属に短波長の光を照射すると電子が表面から飛び出す現象を確認した。

### レーナルトの研究（1902年）

**フィリップ・レーナルト**は光電効果の詳細な研究を行い、以下の重要な事実を明らかにした：

| 観測事実 | 内容 |
|----------|------|
| 限界振動数の存在 | 一定以上の振動数の光でなければ電子は放出されない |
| 光強度の効果 | 光を強くすると放出される電子の数は増えるが、1個あたりの運動エネルギーは変わらない |
| 振動数の効果 | 振動数を大きくすると電子1個の運動エネルギーが増加するが、電子の数は変わらない |
| 即時放出 | 光を当てると瞬時に電子が放出される（遅れがない） |

これらの事実は、光を連続的な波として扱う古典物理学では説明できなかった。

### アインシュタインの光量子仮説（1905年）

1905年、**アルベルト・アインシュタイン**は光電効果を説明するため、光が**光子**（photon）という粒子の集まりであるという**光量子仮説**を提唱した。

**アインシュタインの洞察**:
- 光は振動数 $\nu$ に比例したエネルギー $E = h\nu$ を持つ粒子（光子）である
- 1個の光子が1個の電子にエネルギーを与える（一対一対応）
- 光子のエネルギーが仕事関数を超えなければ電子は放出されない

### ミリカンの実験（1916年）

アメリカの物理学者**ロバート・ミリカン**は精密な実験を行い、アインシュタインの光量子仮説を検証した。彼は光電効果の実験からプランク定数の値を高精度で決定し、1923年にノーベル物理学賞を受賞した。

## アインシュタインの光電効果方程式

### 基本方程式

光電効果は以下の方程式で記述される：

$$K_{\text{max}} = h\nu - \phi$$

| 記号 | 意味 | 単位 |
|------|------|------|
| $K_{\text{max}}$ | 放出電子の最大運動エネルギー | J または eV |
| $h$ | プランク定数（6.626×10⁻³⁴ J·s） | J·s |
| $\nu$ | 入射光の振動数 | Hz |
| $\phi$ | 仕事関数（金属固有の値） | J または eV |

### 仕事関数

**仕事関数**（work function）とは、電子を金属表面から取り出すのに必要な最小エネルギーである。

| 金属 | 仕事関数 (eV) |
|------|--------------|
| セシウム (Cs) | 2.1 |
| カリウム (K) | 2.3 |
| ナトリウム (Na) | 2.4 |
| 亜鉛 (Zn) | 4.3 |
| 銅 (Cu) | 4.7 |
| 金 (Au) | 5.1 |
| 白金 (Pt) | 5.6 |

仕事関数が小さい金属ほど、低いエネルギー（長い波長）の光で電子を放出できる。

### 限界振動数

電子が放出されるための最小振動数を**限界振動数**（threshold frequency）$\nu_0$ という：

$$\nu_0 = \frac{\phi}{h}$$

- $\nu < \nu_0$ の場合：どんなに光を強くしても電子は放出されない
- $\nu \geq \nu_0$ の場合：光電効果が起こる

### 阻止電圧

放出電子の最大運動エネルギーは、**阻止電圧**（stopping voltage）$V_s$ を測定することで求められる：

$$K_{\text{max}} = eV_s$$

ここで $e$ は電気素量（1.602×10⁻¹⁹ C）である。

## 古典物理学との矛盾

光電効果の実験結果は、光を連続的な波として扱う古典物理学と以下の点で矛盾した：

| 観測事実 | 古典物理学の予測 | 実験結果 |
|----------|------------------|----------|
| 限界振動数 | 光強度が十分なら低振動数でも電子放出 | 振動数が限界以下では放出されない |
| エネルギーと光強度 | 光強度に比例して電子エネルギー増加 | 振動数にのみ依存 |
| 放出の時間遅れ | エネルギー蓄積に時間がかかる | 即時放出 |

これらの矛盾は、光が波動ではなく粒子（光子）として振る舞うと考えることで解決された。

## 外部光電効果と内部光電効果

光電効果には大きく分けて2種類がある。

### 外部光電効果

物質表面から真空中へ電子が放出される現象。単に「光電効果」という場合は通常これを指す。

| 特徴 | 内容 |
|------|------|
| 発生条件 | 光子エネルギー > 仕事関数 |
| 放出先 | 真空中 |
| 応用例 | 光電子増倍管、光電管 |

### 内部光電効果

半導体や絶縁体の内部で、価電子帯の電子が伝導帯へ励起される現象。

| 特徴 | 内容 |
|------|------|
| 発生条件 | 光子エネルギー > バンドギャップ |
| 変化 | 導電性の増加 |
| 応用例 | 太陽電池、フォトダイオード、CCDイメージセンサ |

内部光電効果はさらに以下に分類される：
- **光起電力効果**：pn接合で起電力が発生
- **光導電効果**：光照射により導電率が増加

## 応用

### 光電子増倍管（PMT）

**光電子増倍管**（Photomultiplier Tube, PMT）は外部光電効果を利用した超高感度光検出器である。

| 特徴 | 内容 |
|------|------|
| 動作原理 | 光電面から放出された電子をダイノードで増倍 |
| 増倍率 | 10⁶ 〜 10⁷ 倍 |
| 感度 | 光子1個を検出可能（フォトンカウンティング） |
| 応用 | 分光分析、高エネルギー物理学、医療診断（PET、ガンマカメラ） |

### 太陽電池

**太陽電池**は内部光電効果（光起電力効果）を利用して光エネルギーを電気エネルギーに変換する。

| 特徴 | 内容 |
|------|------|
| 動作原理 | pn接合半導体で光により電子-正孔対を生成 |
| 材料 | シリコン、GaAs、CdTeなど |
| 変換効率 | 15〜25%（単結晶シリコン） |
| 応用 | 太陽光発電、宇宙機電源 |

### その他の応用

| 応用 | 利用する効果 | 用途 |
|------|--------------|------|
| CCDイメージセンサ | 内部光電効果 | デジタルカメラ |
| フォトダイオード | 内部光電効果 | 光通信、センサ |
| 光電管 | 外部光電効果 | 光量測定 |
| 光電子分光法 | 外部光電効果 | 物質分析（XPS, UPS） |

## 物理学史における意義

光電効果とその説明は、物理学の発展において極めて重要な役割を果たした。

| 意義 | 内容 |
|------|------|
| 光の粒子性の実証 | 光が波動だけでなく粒子としての性質を持つことを示した |
| 量子力学の基礎 | プランクの量子仮説を発展させ、量子力学誕生の契機となった |
| 波動粒子二重性 | 光の二重性が確立され、後にド・ブロイの物質波仮説へ発展 |
| プランク定数の測定 | 基礎物理定数の精密測定を可能にした |
