## 概要

**パウリの排他原理**（Pauli Exclusion Principle）とは、2つ以上の同種のフェルミ粒子（半整数スピンを持つ粒子）は、同一の量子状態を同時に占有することができないという量子力学の基本原理。1925年にオーストリアの物理学者**ヴォルフガング・パウリ**によって提唱され、パウリの禁制、パウリの排他律、パウリの原理とも呼ばれる。

この原理は、原子内の電子配置から周期表の構造、さらには白色矮星や中性子星の安定性まで、物質の性質を決定する根源的な法則である。

| 特性 | 内容 |
|------|------|
| 発表年 | 1925年 |
| 提唱者 | ヴォルフガング・パウリ |
| 適用対象 | フェルミ粒子（電子、陽子、中性子、クォークなど） |
| 理論的基盤 | スピン統計定理、波動関数の反対称性 |
| 受賞 | 1945年ノーベル物理学賞 |

## 発見の歴史

### 背景（1920年代初頭）

1920年代、原子スペクトルの微細構造を説明するため、物理学者たちは電子の振る舞いを理解しようとしていた。当時、3つの量子数（主量子数 n、方位量子数 l、磁気量子数 m）では原子の全ての性質を説明できないことが明らかになっていた。

### パウリの発見（1925年）

1924年、**エドマンド・ストーナー**の論文にヒントを得たパウリは、閉殻内の電子数を説明するために新しい二値の量子数が必要だと考えた。1925年、パウリは「原子中で2つの電子が同じ量子状態を占めることはできない」という原理を発表。この新しい量子数は、同年**サミュエル・ゴーズミット**と**ジョージ・ウーレンベック**によって**電子スピン**として同定された。

### スピン統計定理の確立（1940年）

1939〜1940年、パウリは弟子の**マルクス・フィールツ**とともに**スピン統計定理**を定式化。この定理は、粒子のスピンとそれが従う統計の関係を示す：

- **整数スピン粒子**（ボース粒子）: ボース・アインシュタイン統計に従う
- **半整数スピン粒子**（フェルミ粒子）: フェルミ・ディラック統計に従う

パウリ自身はノーベル賞講演で「私はこの排他原理の論理的根拠を見つけることも、より一般的な仮定から導出することもできなかった。これは理論に何らかの欠陥があるせいだという感覚が今日まで残っている」と述べた。

## 理論的基礎

### 波動関数の反対称性

フェルミ粒子の多体系において、2つの粒子を入れ替えたとき、全波動関数は符号を反転する（反対称性）：

$$\Psi(r_1, r_2) = -\Psi(r_2, r_1)$$

この反対称性から、2つの粒子が同じ量子状態（$r_1 = r_2$）にあるとき：

$$\Psi(r, r) = -\Psi(r, r) = 0$$

となり、そのような状態の確率がゼロになる。これがパウリの排他原理の数学的表現である。

### スレーター行列式

多電子系の波動関数は**スレーター行列式**で表現される。行列式の性質から、同じ軌道が2回現れると行列式はゼロになり、排他原理が自動的に満たされる。

### 量子数の組み合わせ

原子内の電子の状態は4つの量子数で特徴付けられる：

| 量子数 | 記号 | 取りうる値 | 物理的意味 |
|--------|------|------------|------------|
| 主量子数 | n | 1, 2, 3, ... | 電子殻、エネルギー準位 |
| 方位量子数 | l | 0, 1, ..., n-1 | 軌道角運動量 |
| 磁気量子数 | m | -l, ..., +l | 軌道角運動量のz成分 |
| スピン量子数 | s | ±1/2 | 電子の内部角運動量 |

パウリの排他原理により、4つの量子数の組み合わせが同じ電子は存在できない。

## フェルミ粒子とボース粒子

素粒子はスピンによって2種類に分類され、それぞれ異なる統計に従う。

| 特性 | フェルミ粒子 | ボース粒子 |
|------|--------------|------------|
| スピン | 半整数（1/2, 3/2, ...） | 整数（0, 1, 2, ...） |
| 統計 | フェルミ・ディラック統計 | ボース・アインシュタイン統計 |
| 排他原理 | 適用される | 適用されない |
| 波動関数 | 反対称 | 対称 |
| 例 | 電子、陽子、中性子、クォーク | 光子、グルーオン、ヒッグス粒子 |

→ 詳細: [[Physics/ModernPhysics/素粒子]]

## 物理的意義

### 原子構造と周期表

パウリの排他原理は原子の電子配置を決定する。各軌道にはスピンの異なる2つの電子のみが入ることができ、電子は低いエネルギー準位から順に配置される（**構成原理**）。

| 殻 | 主量子数 n | 最大電子数 |
|----|------------|------------|
| K殻 | 1 | 2 |
| L殻 | 2 | 8 |
| M殻 | 3 | 18 |
| N殻 | 4 | 32 |

この電子配置により、**周期表**の構造が説明される。周期表における元素の化学的性質の周期性は、パウリの排他原理の直接的な帰結である。

### 物質の安定性

パウリの排他原理がなければ、全ての電子は最低エネルギー状態に落ち込み、原子は極端に小さくなる。排他原理により電子は異なるエネルギー準位を占めることを強いられ、これが物質に「大きさ」を与えている。

### 化学結合

電子のスピン対形成（スピンアップとスピンダウン）は化学結合の基礎となる。共有結合では、2つの原子が電子対を共有することで安定化する。

## 縮退圧

### フェルミ縮退

フェルミ粒子の集団が高密度状態にあるとき、パウリの排他原理により全ての粒子が最低エネルギー状態を占めることができず、より高いエネルギー準位を占める。この状態を**フェルミ縮退**という。

絶対零度でも粒子は静止せず、有限の運動量（**フェルミ運動量**）を持つ。これはパウリの排他原理の直接的結果であり、古典力学では説明できない量子効果である。

### 縮退圧の特性

フェルミ縮退した粒子系は圧縮に対して圧力（**縮退圧**）を発生させる：

| 特性 | 内容 |
|------|------|
| 起源 | パウリの排他原理 |
| 温度依存性 | 温度に依存しない |
| 密度依存性 | 密度のみに依存 |
| 発生機構 | 量子状態の占有制限 |

縮退圧は以下の式で近似的に表される（非相対論的極限）：

$$P \propto \left(\frac{N}{V}\right)^{5/3}$$

## 天体物理学への応用

### 白色矮星

質量が太陽の約0.5〜1.4倍の恒星は、進化の最終段階で**白色矮星**になる。白色矮星は**電子縮退圧**によって重力崩壊を免れている。

| 特性 | 値 |
|------|------|
| 支える粒子 | 電子 |
| 典型的質量 | 0.6 M☉ |
| 典型的半径 | 地球程度 |
| 質量上限 | 約1.44 M☉（チャンドラセカール限界） |

→ 詳細: [[Physics/Astronomy/白色矮星]]

### 中性子星

より重い恒星（太陽の約8〜25倍）は超新星爆発の後、**中性子星**を残す。中性子星は**中性子縮退圧**によって支えられている。

| 特性 | 値 |
|------|------|
| 支える粒子 | 中性子 |
| 典型的質量 | 1.4〜2.3 M☉ |
| 典型的半径 | 約10 km |
| 質量上限 | 約2.2〜2.3 M☉（TOV限界） |

→ 詳細: [[Physics/Astronomy/中性子星]]

### 質量限界と重力崩壊

縮退圧には上限があり、それを超える質量の天体は重力崩壊する：

| 限界 | 値 | 崩壊後の天体 |
|------|------|------------|
| チャンドラセカール限界 | 約1.44 M☉ | 中性子星またはIa型超新星 |
| TOV限界 | 約2.2〜2.3 M☉ | ブラックホール |

## その他の応用

### 固体物理学

- **金属の電気伝導**: 伝導電子のフェルミ縮退
- **半導体**: バンド構造と電子配置
- **超伝導**: クーパー対（電子のボース粒子的振る舞い）

### 原子核物理学

- **核の殻構造**: 陽子・中性子の配置
- **魔法数**: 特に安定な原子核の説明

## ノーベル賞

| 年 | 受賞者 | 業績 |
|------|--------|------|
| 1945 | ヴォルフガング・パウリ | 排他原理の発見 |

アルベルト・アインシュタインの推薦により、パウリは1945年のノーベル物理学賞を受賞。受賞理由は「新しい自然法則、すなわち排他原理またはパウリの原理の発見による決定的な貢献」であった。

## 未解決問題

1. **根本的導出**: パウリ自身が認めたように、排他原理の「より深い」根拠は未解明
2. **スピン統計定理の直観的理解**: なぜスピンが統計を決めるのかの直観的説明
3. **違反の探索**: 排他原理の厳密性を検証する精密実験
