## 概要

**ドップラー効果**（ドップラーこうか、英: Doppler effect）とは、波の発生源（音源・光源）と観測者の間に相対的な速度が存在するとき、波の周波数が実際とは異なる値として観測される現象。1842年に**クリスチャン・ドップラー**が理論的に予言し、1845年に**クリストフ・ボイス・バロット**が実験的に証明した。救急車のサイレンの音程変化として日常的に体験される現象であり、気象レーダー、医療用超音波診断、速度測定、天文学的観測など広範な分野で応用される基礎的な波動現象である。

| 項目 | 内容 |
|------|------|
| 理論的予言 | クリスチャン・ドップラー（1842年） |
| 実験的証明 | クリストフ・ボイス・バロット（1845年） |
| 適用対象 | 音波、電磁波、その他あらゆる波動 |
| 近づく場合 | 周波数が高くなる（波長が短くなる） |
| 遠ざかる場合 | 周波数が低くなる（波長が長くなる） |
| 主な応用 | 気象レーダー、医療用超音波、速度測定、天文学 |

## 発見の歴史

### ドップラーの理論的予言（1842年）

1842年、オーストリアの物理学者**クリスチャン・アンドレアス・ドップラー**（1803-1853）は、プラハ工科大学の教授在任中に「二重星と若干の他の天体の色光について」と題する論文を発表。観測される波の振動数が、波源や観測者の運動に依存することを数学的に示した。

| 経歴 | 内容 |
|------|------|
| 生年月日 | 1803年11月29日（オーストリア・ザルツブルク） |
| 没年月日 | 1853年3月17日（イタリア・ヴェネツィア） |
| 職歴 | プラハ工科大学教授、ウィーン大学物理学研究所所長 |
| 著名な教え子 | グレゴール・メンデル（遺伝学の父） |

ドップラーは当初、二重星の色の違いがドップラー効果によるものと考えたが、この仮説は誤りであった。しかし、ドップラー効果そのものの理論は正確であった。

### バロットによる実験的証明（1845年）

1845年、オランダの気象学者**クリストフ・ボイス・バロット**は、ユトレヒトにおいて列車を用いた実験でドップラー効果を証明した。

**実験方法**:
- 列車にトランペット奏者を乗せてG音を演奏させ続ける
- 絶対音感を持つ音楽家が線路脇で音程の変化を観測
- 列車の接近時には音程が高く、遠ざかる時には低く聞こえることを確認

この実験により、ドップラーの理論が実証された。

### その後の発展

| 年 | 出来事 |
|----|--------|
| 1868 | ウィリアム・ハギンズが恒星のドップラー効果を初観測 |
| 1912 | ヴェスト・スライファーが銀河の赤方偏移を発見 |
| 1929 | エドウィン・ハッブルが宇宙膨張を発表 |
| 1950年代 | ドップラーレーダーの実用化 |
| 現代 | 超音波診断、自動運転LiDARなど広範な応用 |

## ドップラー効果の原理

### 基本的なメカニズム

ドップラー効果は以下の2つの要因で生じる。

**1. 音源が動く場合（波長の変化）**

音源が移動しながら音を発するとき：
- 進行方向では波が圧縮され、波長が短くなる → 周波数が高くなる
- 反対方向では波が引き伸ばされ、波長が長くなる → 周波数が低くなる

**2. 観測者が動く場合（相対速度の変化）**

観測者が移動するとき：
- 音源に近づく場合、単位時間あたりに受け取る波の数が増加 → 周波数が高くなる
- 音源から遠ざかる場合、単位時間あたりに受け取る波の数が減少 → 周波数が低くなる

### 日常的な例

| 状況 | 観測される変化 |
|------|----------------|
| 救急車が近づく | サイレンの音が高く聞こえる |
| 救急車が遠ざかる | サイレンの音が低く聞こえる |
| 電車が通過する | 警笛の音程が急に下がる |
| レーシングカー | エンジン音の音程変化 |

## 音波のドップラー効果

### 基本公式

観測者が受け取る周波数 $f'$ は以下の式で表される：

$$f' = \frac{V - v_o}{V - v_s} f$$

| 記号 | 意味 |
|------|------|
| $f'$ | 観測される周波数 |
| $f$ | 音源の本来の周波数 |
| $V$ | 音速（約340 m/s） |
| $v_o$ | 観測者の速度（音源に向かう方向を正） |
| $v_s$ | 音源の速度（観測者に向かう方向を正） |

### 特殊なケース

**観測者が静止、音源が移動する場合**（$v_o = 0$）:

$$f' = \frac{V}{V - v_s} f$$

**音源が静止、観測者が移動する場合**（$v_s = 0$）:

$$f' = \frac{V - v_o}{V} f = \left(1 - \frac{v_o}{V}\right) f$$

### 波長の変化

音源が速度 $v_s$ で移動するとき、進行方向の波長は：

$$\lambda' = \frac{V - v_s}{f} = \lambda \cdot \frac{V - v_s}{V}$$

### 風がある場合

風速 $u$ が吹いている場合（音源から観測者に向かう方向を正）：

$$f' = \frac{(V + u) - v_o}{(V + u) - v_s} f$$

風は音速に加算されるため、媒質全体が移動していると考える。

## 電磁波（光）のドップラー効果

### 古典的な光のドップラー効果

電磁波は媒質を必要としないため、光のドップラー効果は音波とは本質的に異なる。光速は一定であり、相対速度のみが重要となる。

低速近似（$v \ll c$）では：

$$\frac{\Delta\lambda}{\lambda_0} = \frac{\lambda - \lambda_0}{\lambda_0} = \frac{v}{c}$$

| 記号 | 意味 |
|------|------|
| $\lambda_0$ | 光源の静止系での波長 |
| $\lambda$ | 観測される波長 |
| $v$ | 光源の後退速度（正の値） |
| $c$ | 光速（約3×10⁸ m/s） |

### 赤方偏移と青方偏移

| 現象 | 相対運動 | 波長変化 | 可視光の場合 |
|------|----------|----------|--------------|
| 赤方偏移（redshift） | 遠ざかる | 長くなる | 赤い方向へずれる |
| 青方偏移（blueshift） | 近づく | 短くなる | 青い方向へずれる |

→ 詳細: [[Physics/Astronomy/赤方偏移]]

## 相対論的ドップラー効果

### 特殊相対性理論の影響

高速で移動する光源の場合、特殊相対性理論による時間の遅れ（時間膨張）を考慮する必要がある。

### 相対論的ドップラー効果の公式

光源が観測者から視線方向に遠ざかる場合：

$$f' = f \sqrt{\frac{1 - \beta}{1 + \beta}}$$

$$\lambda' = \lambda \sqrt{\frac{1 + \beta}{1 - \beta}}$$

ここで $\beta = v/c$（速度の光速に対する比）。

光源が観測者に近づく場合：

$$f' = f \sqrt{\frac{1 + \beta}{1 - \beta}}$$

### 横ドップラー効果

特殊相対性理論特有の効果として、光源が観測者の視線に垂直な方向に運動する場合でも周波数変化が生じる。これは純粋に時間膨張による効果である：

$$f' = \frac{f}{\gamma} = f\sqrt{1 - \beta^2}$$

ここで $\gamma = 1/\sqrt{1 - \beta^2}$ はローレンツ因子。

### 赤方偏移パラメータ

天文学では赤方偏移パラメータ $z$ が用いられる：

$$z = \frac{\lambda_{obs} - \lambda_{emit}}{\lambda_{emit}} = \frac{\Delta\lambda}{\lambda_{emit}}$$

相対論的ドップラー効果では：

$$1 + z = \sqrt{\frac{1 + \beta}{1 - \beta}}$$

## 応用

### 気象観測（ドップラーレーダー）

**ドップラーレーダー**は、降水粒子からの反射波の周波数変化を観測することで、雲内部の風速・風向を測定する。

| 応用 | 内容 |
|------|------|
| 雨雲の移動 | 降水強度と移動方向の同時把握 |
| ダウンバースト検出 | 空港での航空機安全確保 |
| 竜巻探知 | 回転性の強い風の検出 |
| 台風観測 | 風速分布の立体的把握 |

空港では航空機に危険なダウンバースト（下降噴流）を検出するため、空港気象ドップラーレーダー（DRAW）が設置されている。

**補完技術**:
- ドップラーソーダー（音波）: 晴天時の風観測
- ドップラーライダー（レーザー光）: 高精度な風観測

### 医療用超音波診断

**超音波ドプラ法**は、体内の血流速度を非侵襲的に測定する技術である。

| 種類 | 原理 | 特徴 |
|------|------|------|
| パルスドプラ法（PWD） | 特定深度からの反射波を解析 | 位置特定が可能 |
| 連続波ドプラ法（CWD） | 連続的な超音波の反射を解析 | 高速血流の測定が可能 |
| カラードプラ法 | 血流方向を色で表示 | 視覚的な血流評価 |

**主な用途**:
- 心臓エコー（血流速度、弁逆流の評価）
- 頸動脈エコー（動脈硬化の評価）
- 胎児心拍モニタリング
- 下肢静脈血栓の診断

### 速度測定

| 機器 | 原理 | 用途 |
|------|------|------|
| スピードガン | マイクロ波の反射 | 野球の球速測定 |
| レーダー式速度取締機 | マイクロ波の反射 | 交通取締 |
| LiDAR | レーザー光の反射 | 自動運転車の周囲認識 |
| 航空機対地速度計 | ドップラーナビゲーション | 航空機の対地速度測定 |

### 天文学

天文学ではドップラー効果が天体の視線速度測定に不可欠である。

| 応用 | 内容 |
|------|------|
| 恒星の視線速度 | フラウンホーファー線のずれから算出 |
| 系外惑星探査 | 恒星のふらつき（視線速度法） |
| 銀河の後退速度 | 宇宙膨張の観測的証拠 |
| クエーサーの赤方偏移 | 宇宙初期の天体の距離推定 |

**スペクトル線の観測**:
恒星や銀河のスペクトルに現れる吸収線・輝線の波長が理論値からずれている量（ドップラー・シフト）を測定することで、地球との相対速度を算出できる。

→ 詳細: [[Physics/Astronomy/赤方偏移]]

### その他の応用

| 分野 | 応用例 |
|------|--------|
| 原子炉工学 | ドップラー係数（温度上昇による中性子吸収増加、自己制御性） |
| 通信工学 | 移動体通信での周波数補正 |
| 音響工学 | コンサートホールの音響設計 |
| 地震学 | 地殻変動の観測 |

## 宇宙論的意義

### 宇宙膨張の発見

1920年代、銀河のスペクトル観測によりほぼ全ての銀河が赤方偏移を示すことが発見された。これは宇宙が膨張している証拠として解釈され、**ビッグバン宇宙論**の基礎となった。

**注意**: 遠方銀河の赤方偏移は、厳密にはドップラー効果ではなく「宇宙論的赤方偏移」（空間の膨張による波長の伸び）である。しかし、近距離銀河（数十Mpc以内）ではドップラー解釈が有効。

### ハッブル–ルメートルの法則

銀河の後退速度と距離の関係：

$$v = H_0 \times d$$

- $H_0$: ハッブル定数（約70 km/s/Mpc）
- $d$: 銀河までの距離

この法則の発見にドップラー効果による視線速度測定が決定的な役割を果たした。
