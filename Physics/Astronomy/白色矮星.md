## 概要

![image](https://pub-af1bf2eacb4144a2ba4ea3ff8d6dc608.r2.dev/32c6fea3c9c5ee4e5cc25109d3fc7401.jpeg)

**白色矮星**（White Dwarf）とは、恒星が進化の終末期にとる形態の一つで、電子の縮退圧によって支えられているコンパクト天体。太陽程度の質量を持ちながら、体積は地球程度という極めて高密度な天体であり、中性子星やブラックホールと異なり、比較的軽い恒星（太陽質量の約8倍以下）が辿る最終形態である。

| 特性 | 値 |
|------|------|
| 直径 | 約10,000〜15,000 km（地球程度） |
| 質量 | 太陽の約0.5〜1.4倍（典型的には約0.6倍） |
| 密度 | 約10^4〜10^9 g/cm³ |
| 表面重力 | 地球の約10万〜100万倍 |
| 表面温度 | 約4,000〜100,000 K |
| 冷却時間 | 約100億年以上 |
| 既知の数 | 数万個以上 |

## 発見の歴史

### 最初の発見（19世紀）

1783年、**ウィリアム・ハーシェル**がおおいぬ座の明るい恒星シリウスに暗い伴星があることを示唆。1862年、**アルヴァン・クラーク**がシリウスB（通称「子犬」）を初めて観測で確認した。

1910年、**ヘンリー・ノリス・ラッセル**らがシリウスBの表面温度が高温（約25,000 K）であるにもかかわらず、暗いことを発見。これは体積が非常に小さいことを意味し、驚異的な高密度天体の存在が示唆された。

### 理論的理解（20世紀）

1926年、**ラルフ・ファウラー**が量子力学に基づき、白色矮星が電子の縮退圧で支えられていることを理論的に説明。

1931年、**スブラマニアン・チャンドラセカール**が相対論的効果を考慮し、白色矮星の質量上限（チャンドラセカール限界）を導出。この業績により1983年にノーベル物理学賞を受賞した。

## 形成メカニズム

### 前駆星の条件

白色矮星は以下の条件を満たす恒星から誕生する：

1. **質量**: 太陽の約0.5〜8倍
2. **核融合の進行**: 水素 → ヘリウム → 炭素・酸素まで進行
3. **外層の放出**: 赤色巨星段階で外層を惑星状星雲として放出

### 進化過程

1. **主系列星段階**: 中心核で水素の核融合が進行
2. **赤色巨星段階**: 水素燃料の枯渇後、外層が膨張
3. **ヘリウム燃焼**: 中心温度上昇によりヘリウムが炭素・酸素に変換
4. **外層放出**: 膨張した外層が惑星状星雲として宇宙空間に放出
5. **白色矮星誕生**: 高温・高密度の中心核が残存

太陽は約50億年後に赤色巨星となり、最終的に白色矮星になると予測されている。

## 内部構造

白色矮星の内部は、深さによって異なる構成を持つ。

### 大気層（厚さ〜100 km）

- 水素またはヘリウムで構成
- スペクトル分類の基準となる

| 分類 | 大気組成 | 全体に占める割合 |
|------|----------|------------------|
| DA型 | 水素 | 約80% |
| DB型 | ヘリウム | 約16% |
| DC型 | 連続スペクトル | 約3% |
| DQ型 | 炭素 | 約1% |
| DZ型 | 金属 | 稀 |

### 外殻（厚さ〜50 km）

- 非縮退状態の物質
- エネルギー輸送を制御
- 冷却速度を決定する重要な層

### コア（半径〜5,000 km）

- 完全に縮退した電子ガス
- 炭素・酸素が主成分（典型的な白色矮星）
- 低質量（< 0.4 M☉）ではヘリウム主体
- 高質量（> 1.05 M☉）では酸素・ネオン主体
- 内部温度はほぼ均一

### 結晶化

冷却が進むと、コア内部で結晶化が起こる：

1. **結晶化開始**: 内部温度が約10^7 K以下になると、炭素・酸素イオンが結晶格子を形成
2. **潜熱放出**: 結晶化に伴いエネルギーが放出され、冷却が遅延
3. **元素分離**: 重い元素が中心に沈降し、追加の重力エネルギーを放出
4. **最終形態**: 中心に結晶化したダイヤモンド様構造が形成

## 物理的特性

### 電子縮退圧

白色矮星が潰れずに存在できる理由は**電子縮退圧**にある。

- **パウリの排他原理**: フェルミ粒子（電子）は同じ量子状態を占有できない
- **フェルミ海**: 絶対零度でも電子は高エネルギー状態を占有
- **縮退圧**: 全ての量子状態が占有されると、圧縮に対して強い圧力が発生
- **温度非依存**: 縮退圧は温度ではなく密度のみに依存

### 質量-半径関係

白色矮星は通常の星と異なり、**質量が増加すると半径が減少する**という逆相関を示す。

- 質量増加 → 電子の運動エネルギー増加 → より高密度で平衡
- この関係は縮退物質の特性に起因

### チャンドラセカール限界

| 項目 | 値 |
|------|------|
| 限界質量 | 約1.44 M☉ |
| 発見者 | スブラマニアン・チャンドラセカール |
| 発表年 | 1931年 |
| 意義 | 白色矮星の質量上限を理論的に予測 |

この限界を超えると、電子縮退圧では重力を支えられなくなり、以下のいずれかが起こる：
- **Ia型超新星爆発**: 熱核暴走による爆発
- **中性子星への崩壊**: 電子捕獲により中性子星に変化

### 冷却過程

白色矮星は核融合を行わず、形成時の熱を徐々に放射して冷却する。

1. **初期段階**: 表面温度約100,000 K（青白色）
2. **中期段階**: 数十億年かけて冷却、表面温度約10,000 K（白色）
3. **後期段階**: さらに冷却、表面温度約4,000 K（赤色）
4. **最終段階**: 理論上は「黒色矮星」に至るが、宇宙年齢では実現していない

冷却に要する時間は約100億年以上であり、白色矮星の冷却曲線は宇宙や星団の年齢を推定する「宇宙時計」として利用される。

## Ia型超新星との関係

白色矮星はIa型超新星の起源として重要な役割を果たす。

### 発生シナリオ

| シナリオ | 機構 | 略称 |
|----------|------|------|
| 単一縮退説 | 伴星からの質量降着で限界超過 | SD |
| 二重縮退説 | 白色矮星同士の合体 | DD |

### 単一縮退説（SD説）

1. 白色矮星と伴星（赤色巨星等）の連星系
2. 伴星から白色矮星へ質量が降着
3. 白色矮星がチャンドラセカール限界に到達
4. 炭素の熱核暴走により爆発

### 二重縮退説（DD説）

1. 二つの白色矮星からなる連星系
2. 重力波放出により軌道が縮小
3. 白色矮星同士が合体
4. 合計質量が限界を超え爆発

### 宇宙論的意義

Ia型超新星は光度がほぼ一定であり、「標準光源」として宇宙の距離測定に利用される。1998年の宇宙加速膨張の発見（2011年ノーベル物理学賞）にも貢献した。

## 観測方法

### 可視光観測

- 高温の白色矮星は青白色に輝く
- 固有運動や視差から距離を測定
- スペクトル分析で大気組成を特定

### X線観測

- 降着円盤からの高エネルギー放射を検出
- 激変星（白色矮星連星系）の活動を観測

### 重力波観測

- 白色矮星連星の軌道縮小を検出（将来のLISAミッション）
- Ia型超新星前駆体の探索

## 代表的な白色矮星

| 名称 | 距離 | 特徴 |
|------|------|------|
| シリウスB | 8.6光年 | 最初に発見された白色矮星 |
| プロキオンB | 11.5光年 | 二番目に発見 |
| ヴァン・マーネン星 | 14.1光年 | 最も近い単独白色矮星 |
| BPM 37093 | 50光年 | 結晶化が確認された白色矮星 |
| WD 0525+526 | 128光年 | 合体で形成された白色矮星（2025年確認） |

## 最新の研究成果

### 白色矮星合体の証拠（2025年）

ハッブル宇宙望遠鏡の観測により、白色矮星WD 0525+526が別の白色矮星との合体によって誕生したことが明らかになった。通常の白色矮星とは異なる炭素組成から、衝突の痕跡が特定された。

### Ia型超新星からの電波初検出（2023年）

国立天文台などの研究チームが、Ia型超新星SN 2020eyjからの電波を史上初めて検出。爆発前の白色矮星が伴星から大量の物質を受け取っていたことが判明し、SD説を支持する証拠となった。

### 宇宙の炭素起源（2020年）

白色矮星の質量分布の分析から、宇宙に存在する炭素の大部分が約20億年前に形成された白色矮星から供給されたことが示唆された。

## 未解決問題

1. **Ia型超新星の親星問題**: SD説とDD説のどちらが主要か
2. **冷却異常**: 理論より遅い冷却を示す白色矮星の存在
3. **磁場の起源**: 強磁場白色矮星（最大10^9 G）の形成機構
4. **結晶化の詳細**: 内部構造と相転移の物理
5. **超低質量白色矮星**: 単独形成は宇宙年齢では不可能、連星系での剥ぎ取りが必要
