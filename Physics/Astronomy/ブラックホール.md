## 概要

**ブラックホール**（Black Hole）とは、極めて強い重力により、光さえも脱出できない時空領域を持つ天体。一般相対性理論が予言する究極の重力現象であり、質量が中心の一点（特異点）に集中し、その周囲に「事象の地平面」と呼ばれる境界が形成される。事象の地平面の内側から外部へ情報を伝達することは原理的に不可能であり、ブラックホールの内部構造は直接観測できない。

| 特性 | 値 |
|------|------|
| 恒星質量ブラックホール | 約5〜100 M☉ |
| 超大質量ブラックホール | 約10^6〜10^10 M☉ |
| いて座A*（天の川銀河中心） | 約400万 M☉ |
| M87*（楕円銀河M87中心） | 約65億 M☉ |
| シュヴァルツシルト半径（太陽質量） | 約3 km |
| シュヴァルツシルト半径（地球質量） | 約9 mm |
| 初の重力波検出 | 2015年9月14日（GW150914） |
| 初の直接撮影 | 2019年4月10日（M87*） |

## 発見の歴史

### 理論的予言（18〜20世紀初頭）

1783年、イギリスの聖職者・自然哲学者**ジョン・ミッチェル**が、ニュートン力学に基づき「脱出速度が光速を超える暗黒星」の概念を提唱。1796年には**ピエール＝シモン・ラプラス**も同様の考えを発表した。

### シュヴァルツシルト解（1916年）

1915年、**アルベルト・アインシュタイン**が一般相対性理論を発表。その直後、ドイツの天文学者**カール・シュヴァルツシルト**がアインシュタイン方程式の最初の厳密解を導出した。この解は、質量が一点に集中した場合に特殊な球形領域が発生することを示し、後にブラックホールの理論的基盤となった。シュヴァルツシルトは第一次世界大戦中にロシア戦線で従軍しながらこの発見を行い、アインシュタインに手紙で報告した。

### カー解と回転ブラックホール（1963年）

1963年、ニュージーランドの数学者**ロイ・カー**が、回転するブラックホールの厳密解（カー解）を導出。現実のブラックホールの多くは回転していると考えられ、カー・ブラックホールのモデルが重要となる。

### 命名と理論の発展（1960年代〜1970年代）

「ブラックホール」という名称は1967年、物理学者**ジョン・ホイーラー**が講演中に使用して広まった。

1965年、**ロジャー・ペンローズ**が「特異点定理」を発表。物理的に自然な条件下でブラックホールが形成されることを数学的に証明し、一般相対論にとって最も重要な貢献と評された（2020年ノーベル物理学賞）。

1974年、**スティーヴン・ホーキング**がブラックホールからの熱的放射（ホーキング放射）を理論的に予言し、ブラックホールが蒸発する可能性を示した。

## 構造と物理

### 事象の地平面（イベント・ホライズン）

事象の地平面とは、ブラックホールからの脱出速度が光速に等しくなる境界面。この境界の内側から外部へ情報を伝達することは原理的に不可能であり、地平線の向こうが見えないことに例えて「事象の地平面」と呼ばれる。

球対称で回転しないブラックホール（シュヴァルツシルト・ブラックホール）では、事象の地平面の半径はシュヴァルツシルト半径 r_s = 2GM/c² で与えられる。

### 特異点

ブラックホールの中心には、密度が無限大になる**特異点**が存在すると古典的一般相対論は予言する。特異点では既知の物理法則が破綻し、量子重力理論による記述が必要とされる。

### エルゴ領域（回転ブラックホール）

カー・ブラックホールでは、事象の地平面の外側に**エルゴ領域**と呼ばれる領域が存在する。この領域では時空の引きずり効果（フレーム・ドラッギング）が非常に強く、静止することが物理的に不可能となる。

## ブラックホールの種類

### 恒星質量ブラックホール

太陽の約20倍以上の質量を持つ大質量星が超新星爆発を起こした後に形成される。質量は約5〜100太陽質量。中性子星の質量上限（TOV限界：約2.2〜2.3 M☉）を超えると、中性子縮退圧でも重力を支えられずブラックホールに崩壊する。

→ 形成過程の詳細: [[Physics/Astronomy/超新星爆発]]、[[Physics/Astronomy/中性子星]]

### 超大質量ブラックホール

ほとんどの銀河の中心に存在すると考えられる、太陽の数百万〜数十億倍の質量を持つブラックホール。形成メカニズムは未解明だが、初期宇宙での直接崩壊や、より小さなブラックホールの合体・成長が候補として挙げられている。

活発に物質を吸収している超大質量ブラックホールは**活動銀河核（AGN）**や**クエーサー**として観測される。

### 中間質量ブラックホール

質量が約100〜10万太陽質量の「中間的な」ブラックホール。恒星質量と超大質量の間を埋める存在として探索が続けられており、密な星団内での合体により形成される可能性がある。

### 原始ブラックホール（仮説）

ビッグバン直後の高密度環境で形成された可能性のあるブラックホール。非常に小さな質量から大質量まで幅広い質量を持ちうる。ダークマターの候補として検討されているが、現時点では確認されていない。

## ブラックホール熱力学

### エントロピーと面積

1970年代、**ヤコブ・ベッケンシュタイン**はブラックホールが熱力学的エントロピーを持つことを提唱。ブラックホールのエントロピーは事象の地平面の**表面積**に比例するという画期的な発見であった。

通常の物体では情報量（エントロピー）は体積に比例するが、ブラックホールでは表面積に比例する。これは空間が持てる情報量に上限があることを示唆し、**ホログラフィー原理**の重要な根拠となった。

### ホーキング放射

1974年、**スティーヴン・ホーキング**は量子効果を考慮すると、ブラックホールは熱的放射を行うことを示した。事象の地平面付近での量子揺らぎにより粒子対が生成され、一方が外部へ逃げ出すことで放射が生じる。この放射により、ブラックホールは極めて長い時間をかけて蒸発し、最終的に消滅すると予測される。

### 情報パラドックス

ホーキング放射によりブラックホールが蒸発すると、内部に落ちた物質の情報はどうなるのか。量子力学では情報は保存されるべきだが、ブラックホールの蒸発後に情報が失われるように見える。これが**ブラックホール情報パラドックス**である。

現在、ホログラフィー原理（特にAdS/CFT対応）により情報は実際には保存されると考える物理学者が多い。2004年、ホーキング自身も情報は保存されると認めた。

→ 詳細: [[Physics/ModernPhysics/ホログラフィー原理]]、[[Physics/ModernPhysics/量子重力]]

## 観測方法と成果

### X線観測

ブラックホールは光を放出しないが、周囲から物質を吸収する際に形成される**降着円盤**は極めて高温となり、強力なX線を放射する。連星系におけるX線源の観測が、ブラックホール候補天体の発見に貢献してきた。

最初のブラックホール候補天体**はくちょう座X-1**は1964年に発見され、1972年にブラックホールである可能性が指摘された。

### 重力波観測

2015年9月14日、アメリカの重力波検出器**LIGO**が、約13億光年先で起きた2つのブラックホール（約36 M☉と約29 M☉）の合体からの重力波**GW150914**を史上初めて直接検出した。合体により約62 M☉のブラックホールが形成され、約3太陽質量分のエネルギーが重力波として放出された。

この検出は一般相対論の予言を検証するとともに、ブラックホールの存在を動的に実証した（2017年ノーベル物理学賞）。その後、ブラックホール連星・中性子星連星・ブラックホール−中性子星連星の合体など、多数の重力波イベントが観測されている。

### 直接撮影（イベント・ホライズン・テレスコープ）

2019年4月10日、国際共同プロジェクト**イベント・ホライズン・テレスコープ（EHT）**が、楕円銀河M87中心の超大質量ブラックホール**M87***の撮影に成功した。これは史上初のブラックホール・シャドウの直接撮像であり、リング状に輝く降着円盤の中心に暗い影（シャドウ）が確認された。

2022年5月12日、EHTは天の川銀河中心の超大質量ブラックホール**いて座A***の撮影にも成功。M87*と比較して約1600分の1の質量だが、同様のリング構造が観測された。

## 最新の研究成果

### M87ブラックホールの時間変化（2024〜2025年）

EHTによる2017年・2018年の観測データ比較から、M87*周囲のリング構造が約1年で変化していることが判明。降着円盤の乱流が明るさの変化に影響していると考えられている。また、ガス円盤が逆回転している可能性も提言された。

### いて座A*の磁場構造（2024年）

いて座A*の偏光観測から、M87*に類似した渦巻き状の磁場構造が発見された。ブラックホール周囲のガスとの相互作用において、秩序だった強い磁場が重要な役割を果たしていることが示された。

### M87に第2のブラックホール？（2025年）

M87のジェットに見られる約11年周期の歳差運動や約0.9年周期の揺れから、第2の超大質量ブラックホールが存在する可能性が検討されている。

### 事象の地平面がない新説（2020年〜）

理化学研究所の研究では、量子効果を考慮すると「ブラックホールは事象の地平面を持たない高密度な物体」である可能性が示された。この説では、物質の収縮と蒸発が釣り合い、事象の地平面も特異点も形成されないとされる。

## 未解決問題

1. **特異点の物理**: 特異点で何が起きているか、量子重力理論による記述が必要
2. **情報パラドックス**: ブラックホール蒸発時の情報保存の詳細なメカニズム
3. **超大質量ブラックホールの形成**: 初期宇宙でどのように形成されたか
4. **量子重力理論**: 一般相対論と量子力学を統合する理論の構築
5. **時空のミクロ構造**: 空間が連続体か「粒々」でできているかの検証
