## 概要

**中性子星**（Neutron Star）とは、大質量星が超新星爆発を起こした後に残るコンパクト天体。主成分は中性子であり、宇宙で最も密度の高い観測可能な天体の一つ。白色矮星とブラックホールの間に位置する極限状態の天体として、原子核物理学・一般相対性理論・量子力学が交差する重要な研究対象。

| 特性 | 値 |
|------|------|
| 直径 | 約20 km |
| 質量 | 太陽の約1.4〜2.3倍 |
| 密度 | 約10^9 t/cm³ |
| 表面重力 | 地球の約2000億倍 |
| 脱出速度 | 光速の約1/3 |
| 表面温度 | 約10^6 K（形成直後） |
| 既知の数 | 約3,000個以上 |

## 発見の歴史

### 理論的予言（1930年代）

1932年、**ジェームズ・チャドウィック**が中性子を発見。翌1933年、**フリッツ・ツビッキー**と**ウォルター・バーデ**が超新星爆発の後に中性子で構成された天体が残る可能性を初めて提唱した。

1939年、**オッペンハイマー**と**ヴォルコフ**がTOV方程式（Tolman-Oppenheimer-Volkoff方程式）を導出し、中性子星の構造を一般相対性理論に基づいて記述する理論的基盤を確立した。

### パルサーの発見（1967年）

1967年、ケンブリッジ大学の大学院生**ジョスリン・ベル・バーネル**が、周期的な電波パルスを放射する天体を発見。当初は「緑の小人」(LGM-1: Little Green Man)と呼ばれ、地球外知的生命体の可能性も検討された。

最初のパルサー **PSR B1919+21**（旧名 CP 1919）は周期1.337秒で電波パルスを放射。1968年、これが高速回転する中性子星であることが確認され、中性子星の存在が実証された。

## 形成メカニズム

### 前駆星の条件

中性子星は以下の条件を満たす恒星から誕生する：

1. **質量**: 太陽の約8〜25倍
2. **核融合の進行**: 水素 → ヘリウム → 炭素 → ... → 鉄まで進行
3. **鉄コアの形成**: 核融合でエネルギーを放出しない鉄が中心部に蓄積

### 超新星爆発と誕生

1. **鉄コアの崩壊**: 核融合停止後、鉄コアは自己重力で急速に収縮
2. **電子捕獲**: 陽子が電子を捕獲し中性子に変換（逆ベータ崩壊）
   - p + e⁻ → n + νₑ
3. **縮退圧による停止**: 中性子の縮退圧でコア収縮が停止
4. **衝撃波の発生**: 落下する外層がコアで跳ね返り、超新星爆発を引き起こす
5. **中性子星の誕生**: 中心に中性子星が残存

## 内部構造

中性子星の内部は、深さによって異なる状態に分かれる。

### 大気層（厚さ〜1 m）

- 水素・ヘリウム等の軽元素で構成
- X線放射の主な発生源

### 外殻（厚さ〜1 km）

- 中性子過剰な原子核と電子の固体格子
- 密度: 10^6〜10^11 g/cm³

### 内殻

- 原子核が「ドリップ」して中性子が染み出す領域
- **核パスタ構造**: 極限的圧力で原子核が特殊な形状を形成

| 構造名 | 形状 | 密度領域 |
|--------|------|----------|
| ニョッキ | 球状クラスター | 表層 |
| スパゲッティ | ひも状構造 | 中間層 |
| ラザニア | 層状構造 | 深層 |
| 反スパゲッティ | 管状空洞 | より深層 |
| 反ニョッキ | 球状空洞 | 最深層 |

### コア（半径〜10 km）

- 中性子・陽子・電子・ミューオンの超流動状態
- 密度が原子核密度（2.8×10^14 g/cm³）を超過
- **ハイペロン**（ストレンジクォークを含む粒子）や**クォーク物質**が存在する可能性
- 物質の状態方程式（EoS）は未確定

## 物理的特性

### 中性子縮退圧

中性子星が潰れずに存在できる理由は**縮退圧**にある。

- **パウリの排他原理**: フェルミ粒子（中性子）は同じ量子状態を占有できない
- 全ての量子状態が占有されると、追加の圧縮に対して強い圧力（縮退圧）が発生
- この圧力が重力と釣り合い、星を支える

### 質量限界

| 限界 | 値 | 説明 |
|------|------|------|
| チャンドラセカール限界 | 約1.4 M☉ | 白色矮星の質量上限 |
| TOV限界（理論値） | 約2.2〜2.3 M☉ | 中性子星の質量上限 |
| 最大観測質量 | 2.35±0.17 M☉ | PSR J0952-0607（2022年） |

TOV限界を超えると、縮退圧でも重力を支えられず**ブラックホール**に崩壊する。

### ブラックホールへの遷移

中性子星がブラックホールに変わる過程は、**ハイゼンベルグの不確定性原理**で説明される：

1. 物質が追加されると中性子の位置がより正確に確定
2. 不確定性原理により、運動量の不確定性が増大
3. 新たな量子状態（「座席」）が利用可能になる
4. パウリの排他原理に違反せずに収縮が進行
5. 事象の地平線が形成されブラックホールに

## 中性子星の種類

### パルサー（Pulsar）

高速回転する中性子星で、磁極から電磁波ビームを放射。回転に伴いビームが地球を掃くことで周期的なパルスとして観測される。

| パルサータイプ | 周期 | 特徴 |
|----------------|------|------|
| 通常パルサー | 0.1〜数秒 | 回転エネルギーで放射 |
| ミリ秒パルサー | 1〜10 ms | 降着による「リサイクル」で高速化 |
| X線パルサー | 様々 | 連星系での降着によるX線放射 |

### マグネター（Magnetar）

極端に強い磁場（10^9〜10^11 T）を持つ中性子星。

- ソフトガンマ線リピーター（SGR）
- 異常X線パルサー（AXP）

→ 詳細: [[Physics/ModernPhysics/マグネター]]

### スパイダーパルサー

連星系で伴星を蒸発させているパルサー。

| 種類 | 伴星質量 | 名前の由来 |
|------|----------|------------|
| ブラックウィドウ | < 0.1 M☉ | 交尾後に雄を食べるクロゴケグモ |
| レッドバック | > 0.1 M☉ | オーストラリアのセアカゴケグモ |

### その他

- **CCO（Compact Central Objects）**: 超新星残骸中心の軟X線源
- **RRAT（Rotating Radio Transients）**: 間欠的な電波パルス
- **XINS（X-ray Isolated Neutron Stars）**: 孤立したX線中性子星

## 観測方法

### 電波観測

- パルサーの周期的電波パルスを検出
- 自転周期、周期変化率、磁場強度を推定
- 現在約3,000個のパルサーが発見済み

### X線観測

- 表面からの熱放射を観測
- X線パルサー、マグネターの活動を検出
- NICER（中性子星内部組成探査機）による精密測定

### 重力波観測

- **GW170817**（2017年）: 中性子星連星合体からの重力波を初検出
- 状態方程式（EoS）の制約に貢献
- キロノヴァ（重元素合成）の確認

## 最新の研究成果

### SN 1987A残骸での直接確認（2024年）

ジェームズ・ウェッブ宇宙望遠鏡（JWST）により、1987年に観測された超新星SN 1987Aの残骸内部で中性子星が37年ぶりに確認された。超新星爆発後の中性子星形成を直接証明する重要な成果。

### 状態方程式の精密化（2024年）

重力波観測と理論的制約の組み合わせにより：

- 1.4 M☉中性子星の半径: R₁.₄ = 12.20⁺⁰·⁵⁰₋₀.₄₈ km
- TOV質量上限: M_TOV = 2.30⁺⁰·⁰⁷₋₀.₂₀ M☉

### X線明るさと回転スピードの関係（2025年）

立教大学などの研究グループが、中性子星NGC 7793 P13において、ガス降着によるX線明るさと自転速度の未知の関連性を発見。

## 未解決問題

1. **状態方程式（EoS）**: コア内部の物質状態が未確定
2. **ハイペロンパズル**: ハイペロンの存在が質量限界と矛盾する可能性
3. **クォーク物質**: コア中心部にクォーク星が存在するか
4. **グリッチ現象**: パルサーの突発的な周期変化のメカニズム
5. **パルサー放射機構**: 電波放射の詳細な物理過程
